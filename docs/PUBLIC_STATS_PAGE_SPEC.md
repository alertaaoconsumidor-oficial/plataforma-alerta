# Especificação da Página Estatística Pública

## Objetivo

Criar uma página pública demonstrativa com dados fictícios, agregados e anonimizados, preservando a identidade visual atual do site.

## Rota

```txt
/casos/[caseSlug]/estatisticas
```

## Blocos

1. Cabeçalho com nome do caso ou empresa.
2. Aviso de painel demonstrativo.
3. Cards principais.
4. Gráfico mensal.
5. Gráfico por status.
6. Gráfico por faixa de prejuízo.
7. Indicador de documentação apresentada.
8. Tabela por cidade/Estado.
9. Aviso LGPD.

## Métricas iniciais

- Total de relatos.
- Valor total estimado.
- Cidades afetadas.
- Estados afetados.
- Tempo médio sem solução.
- Relatos com documentação.
- Distribuição por tipo de problema.

## Regras

- Dados devem ser fictícios.
- A página deve informar que o painel é demonstrativo.
- Nenhum dado pessoal deve aparecer.
- Nenhum documento deve aparecer.
- Nenhum upload deve ser criado.
