# Diretrizes de LGPD, Privacidade e Segurança

## Princípios

- Coletar o mínimo necessário.
- Informar finalidade.
- Separar dados privados de dados públicos.
- Anonimizar antes de publicar.
- Registrar consentimentos.
- Proteger documentos.
- Registrar ações sensíveis.

## Dados públicos permitidos

- Estatísticas agregadas.
- Cidade e estado em nível agregado.
- Faixas de valores.
- Quantidade de relatos.
- Status geral.
- Versão pública moderada, quando existir.

## Dados privados

- Nome.
- E-mail.
- Telefone.
- Documentos pessoais.
- Comprovantes.
- Prints.
- Relato completo.
- Dados bancários.

## Upload de documentos

Upload só pode existir depois de:

- autenticação;
- autorização;
- storage privado;
- validação de tipo e tamanho;
- URL assinada temporária;
- log de acesso;
- política de retenção e exclusão.

## Regras públicas

- Não publicar dados pessoais.
- Não publicar documentos.
- Não publicar relato automaticamente.
- Não exibir localização precisa.
- Não expor nomes de funcionários ou terceiros sem necessidade legal.

## Segurança mínima futura

- RLS ou regras equivalentes.
- Rate limit.
- Proteção contra XSS e CSRF quando aplicável.
- Logs de auditoria.
- Backups.
- Monitoramento.
- Plano de resposta a incidentes.
