## Regra central

Público vê somente dados agregados, anonimizados e moderados. A vítima vê seus próprios dados. Moderadores revisam versões públicas. Documentos ficam privados. Ações sensíveis devem ser registradas.

## Documentos removidos

O arquivo `docs/blueprint.md` foi removido por representar uma direção inicial já superada pela identidade visual atual do site e pelos documentos de produto mais recentes.

O roadmap longo original foi consolidado nos documentos atuais para reduzir repetição e facilitar execução.
